# 毕业设计启动包

## 项目名称

**面向经营分析场景的指标语义约束智能分析Agent设计与实现**

## 你现在最该做的事

在正式开始开发和写论文前，不要急着直接“做 Agent”。你先要把项目最核心的 4 类材料准备好，让 Trae 能稳定理解你的目标、数据、指标口径和边界。

这 4 类材料分别是：

1. **研究目标材料**
2. **数据与表结构材料**
3. **指标与语义规则材料**
4. **实验与评测材料**

如果这四类材料没准备好，后面无论是让 Trae 帮你写代码、写论文、搭系统，还是做实验，都会反复返工。

---

## 一、开始前要明确什么

在项目开始前，你必须先把下面这些问题想清楚。

### 1. 你到底要做什么

一句话定义项目：

**做一个面向经营分析场景的智能分析 Agent，在指标语义约束下完成自然语言问题理解、查询生成、结果校验与分析输出，并验证其比普通问数流程更可靠。**

### 2. 你不做什么

为了控制难度，建议明确不做以下内容：

- 不做企业级完整产品
- 不做复杂前端系统
- 不做开放式聊天机器人
- 不做多智能体协作
- 不做超长多轮对话
- 不做特别复杂的可视化平台

### 3. 你要做到什么程度

建议你把目标定在：

- 一个可运行原型
- 一个小型经营分析数据集
- 一套指标语义规则库
- 一组典型分析任务
- 一套对比实验

这已经足够支撑本科毕业设计。

---

## 二、需要准备哪些材料

下面这些材料，是你接下来最需要准备给 Trae 的。

## 1. 研究目标材料

你需要准备：

- 论文题目
- 开题报告
- 研究目标
- 研究边界
- 核心功能列表

你现在已经有：

- 题目
- 开题报告初稿

你还需要补：

- 你准备实现的最小系统范围
- 你准备对比的基线方案
- 你最终想展示的核心结果

建议整理成一页文字说明。

---

## 2. 数据与表结构材料

这是后面能不能落地的基础。

你需要准备：

- 数据来源说明
- 原始数据文件
- 清洗后数据文件
- 表结构说明
- 每张表字段含义
- 主键、外键、关联关系

最理想的形式是：

1. 一个 `data/` 文件夹
2. 一份字段说明文档
3. 一张数据关系图

如果暂时没有正式数据，你也至少要先准备：

- 一个公开零售/交易/电商数据集
- 简单的订单表、客户表、商品表、时间表

---

## 3. 指标与语义规则材料

这是你这个项目最核心的部分。

你需要准备：

- 指标名称
- 指标定义
- 指标计算公式
- 指标同义词
- 时间范围规则
- 维度限制
- 指标解释模板

例如你至少要先准备 5 到 8 个核心指标：

- 销售额
- 订单量
- 客单价
- 复购率
- 新客数
- 活跃客户数
- 商品转化率
- 区域销售占比

然后每个指标都要明确：

- 它到底怎么算
- 它有哪些别名
- 它能和哪些维度一起分析
- 它有哪些容易被混淆的口径

这部分建议单独整理成一份“指标语义表”。

---

## 4. 实验与评测材料

你不能只做个 demo，还要有实验。

所以你要提前准备：

- 任务测试集
- 正确答案或参考 SQL
- 基线系统说明
- 评测指标说明

建议你准备：

- 20 到 30 条经营分析问题
- 每条问题对应：
  - 标准指标
  - 时间范围
  - 涉及维度
  - 参考 SQL
  - 正确结果说明

评测指标建议提前定好：

- SQL 执行成功率
- 指标语义一致性
- 任务完成率
- 平均修正次数
- 人工修正成本

## 四、让 Trae 更好理解你需求的关键

Trae 最怕的不是任务难，而是上下文不完整。

所以你每次让 Trae 帮你做事时，最好同时提供这 5 类信息：

1. **你现在在做哪个阶段**
   例如：
   - 在做数据准备
   - 在做指标语义库
   - 在做 Agent 原型
   - 在做实验评测

2. **你希望它输出什么**
   例如：
   - 帮我生成字段说明文档
   - 帮我设计 SQL 基线
   - 帮我写语义规则 JSON
   - 帮我写评测脚本

3. **你的输入材料是什么**
   例如：
   - 订单表 CSV
   - 客户表 CSV
   - 指标定义草稿
   - 20 条测试问题

4. **边界和约束是什么**
   例如：
   - 只做本科可实现版本
   - 不做多 Agent
   - 先只支持 5 个指标
   - 先只支持单轮问题

5. **你最终如何判断它做得对**
   例如：
   - 能输出字段说明表
   - 能生成正确 SQL
   - 能匹配指标定义
   - 能跑通 20 条测试样例

## 五、项目开始前的标准准备清单

在正式启动前，你最好确认下面这些都已经准备到位。

### A. 选题与研究部分

- 论文题目已确定
- 开题报告已完成初稿
- 项目边界已明确
- 已确定“做什么”和“不做什么”

### B. 数据部分

- 已选定一个公开数据集
- 已拿到原始数据文件
- 已梳理出核心表结构
- 已写出主要字段说明

### C. 指标部分

- 已选定 5 到 8 个核心经营分析指标
- 已整理指标定义
- 已整理同义词与别名
- 已整理时间和维度约束

### D. 系统部分

- 已确定原型系统模块
- 已确定不做多 Agent
- 已确定先做单 Agent 工作流
- 已确定输出形式

### E. 实验部分

- 已准备 20 到 30 条测试问题
- 已准备参考 SQL 或标准答案
- 已确定基线方案
- 已确定评测指标

---

## 六、推荐你的启动顺序

不要一上来就写 Agent。

建议按这个顺序推进：

1. 选数据集
2. 建表结构和字段说明
3. 定核心指标和语义规则
4. 写测试问题集
5. 搭最小 SQL 基线
6. 再做 Agent 原型
7. 最后做实验和论文写作

---

## 七、你现在立刻要做的事情

如果今天就开始，优先做下面 3 件事：

1. 选一个合适的公开经营分析数据集
2. 先定义 5 个核心指标及其口径
3. 先写出 20 条你希望 Agent 能回答的问题

只要这三步完成，Trae 后面就能非常高效地继续帮你往下做。

---

## 八、和 Trae 协作时的原则

### 原则一
不要一次让它做太大任务。

错误示例：

“帮我做完整毕业设计系统。”

正确示例：

“这是订单表和客户表，帮我先生成字段说明文档和表关系说明。”

### 原则二
每一步都给它明确输入。

例如：

- 数据文件
- 指标定义
- 测试问题
- 当前代码

### 原则三
每一步都要求它生成可复用成果。

例如：

- Markdown 文档
- JSON 规则文件
- Python 脚本
- SQL 样例
- 实验记录表

---

## 九、你真正要准备好的心态

这个项目本质上不是“让 AI 帮你自动完成”，而是：

**你负责定义问题、准备语义和数据，Trae 负责帮你把项目拆开、写文档、写代码、做实验和不断收敛。**

所以前期准备越扎实，后期效率越高。

---

## 十、结论

如果你要正式启动这个毕业设计，最重要的不是马上开发，而是先准备：

- 一个明确可控的项目边界
- 一套经营分析数据
- 一组指标语义定义
- 一份测试问题集
- 一套评测标准

只要这些准备充分，Trae 就能很好地理解你的需求，并持续帮你完成后续开发和论文工作。
