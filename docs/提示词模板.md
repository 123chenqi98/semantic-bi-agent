# Trae 协作提示词模板

下面这些模板可以直接复制给 Trae 使用。建议每次只做一个小任务。

## 模板一：项目初始化

```md
我现在在做本科毕业设计，题目是《面向经营分析场景的指标语义约束智能分析Agent设计与实现》。

我的目标是做一个本科可实现版本，不做企业级产品，不做多智能体，不做复杂前端。

请你作为我的项目协作助手，先根据我给你的材料，帮我整理：
1. 项目范围
2. 系统模块
3. 最小可行版本
4. 分阶段开发计划

我接下来会给你我的开题报告和已有文档。
```

## 模板二：数据准备

```md
这是我的数据文件和表结构信息。请你帮我：
1. 梳理每张表的字段含义
2. 判断主键、外键和关联关系
3. 生成字段说明文档
4. 给出适合经营分析的表结构设计建议

要求输出为 Markdown。
```

## 模板三：指标语义规则

```md
这是我定义的经营分析指标，请你帮我把它们整理成可用于系统开发的“指标语义规则表”。

每个指标需要包含：
1. 指标名称
2. 指标定义
3. 计算公式
4. 同义词
5. 时间范围规则
6. 支持分析的维度
7. 易混淆口径说明

请输出成 Markdown 表格，如果合适，也可以补充 JSON 结构。
```

## 模板四：测试问题集

```md
请基于我的数据表和经营分析场景，帮我设计 30 条测试问题，供我的智能分析 Agent 使用。

每条问题请包含：
1. 自然语言问题
2. 涉及的指标
3. 涉及的维度
4. 时间范围
5. 问题类型（趋势、对比、排名、异常、归因）

要求问题贴近经营分析真实场景。
```

## 模板五：基线 SQL 设计

```md
下面是我的测试问题和数据表结构。请你帮我为每个问题生成参考 SQL。

要求：
1. SQL 可执行
2. 与指标定义一致
3. 如果问题有歧义，请先标注风险
4. 给出简短解释说明这个 SQL 为什么符合口径
```

## 模板六：Agent 原型设计

```md
我现在要做一个本科可实现版本的智能分析 Agent。

已知：
1. 数据表结构已整理
2. 指标语义规则已定义
3. 测试问题集已准备

请你帮我设计一个单 Agent 原型系统，要求：
1. 支持自然语言问题理解
2. 支持指标语义匹配
3. 支持 SQL 生成与执行
4. 支持结果校验
5. 支持简要结果说明

请输出：
1. 系统架构说明
2. 模块划分
3. 输入输出定义
4. 代码目录建议
```

## 模板七：实验评测设计

```md
我现在要为毕业设计做实验评测。

项目题目是《面向经营分析场景的指标语义约束智能分析Agent设计与实现》。

请你帮我设计实验方案，要求包括：
1. 基线系统定义
2. 实验组定义
3. 评测指标
4. 数据记录方式
5. 结果分析方式

重点关注：
- SQL 执行准确率
- 指标语义一致性
- 任务完成率
- 人工修正成本
```

## 模板八：论文协作

```md
我正在写毕业论文，题目是《面向经营分析场景的指标语义约束智能分析Agent设计与实现》。

请你根据我已有的项目材料，帮我撰写以下部分：
[这里写你要写的章节名称]

要求：
1. 保持计算机/数据科学专业论文风格
2. 语言正式
3. 内容不要空泛
4. 要结合我的系统实现和实验设计
```
