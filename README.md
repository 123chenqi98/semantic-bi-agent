# 面向经营分析场景的指标语义约束智能分析Agent设计与实现

本科毕业设计项目。

## 项目简介

本项目设计并实现一个面向经营分析场景的智能分析 Agent，在指标语义约束下完成自然语言问题理解、查询生成、结果校验与分析输出，并验证其比普通问数流程更可靠。

## 项目边界

### 做什么
- 一个可运行的单 Agent 原型系统
- 基于公开零售/电商数据集的经营分析场景
- 5-8 个核心经营分析指标的语义约束建模
- 支持自然语言问数、SQL 生成、结果校验、洞察输出
- 与基线方案的对比实验

### 不做什么
- 不做企业级完整产品
- 不做复杂前端系统（仅提供命令行或简单 Web Demo）
- 不做开放式聊天机器人（仅支持经营分析相关问题）
- 不做多智能体协作（单 Agent 工作流）
- 不做超长多轮对话（支持单轮+简单追问）
- 不做特别复杂的可视化平台（输出表格+简单图表）
